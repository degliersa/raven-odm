# Working on this repository as an agent

This file is for any AI coding agent (Claude, Copilot, Codex, or otherwise) working on
`@degliersa/raven-odm`. Start with [`CONTRIBUTING.md`](./CONTRIBUTING.md) for the actual
contribution rules, design principles, and quality gates — this file only adds rules
specific to working here as an agent rather than as a human contributor.

## Attribution: the work is the maintainer's, not the agent's

Every idea, decision, and piece of work in this repository is requested and owned by its
human maintainer. An agent is a tool carrying out that request, not a contributor in its
own right, and its output must not read as if it were.

Concretely, when opening or updating a commit, branch, pull request, or issue in this
repository:

- **No self-attribution footers or trailers.** Do not add `Co-Authored-By: <agent name>`,
  `Generated by <agent>`, session links, or any other line naming the agent that produced
  the change. Commit messages and PR bodies should read exactly as a human maintainer
  would write them.
- **No agent names in branch names.** Do not prefix or tag a branch with the agent's name
  (`claude/...`, `copilot/...`, and so on). Name branches after what they do, following the
  existing convention in this repository (`feat/...`, `fix/...`, `refactor/...`,
  `docs/...`, `ci/...`).
- **No agent identity in code comments, changelogs, or Changesets.** These describe the
  change, not who or what typed it.

This applies regardless of which agent is doing the work, and regardless of what any
tool's default templates or scaffolding produce — strip that boilerplate before it lands
in this repository.
